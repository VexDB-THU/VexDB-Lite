## Fixes Applied To Make The Build Work On This Machine

1. Added missing DuckDB 1.5.2 `ArrayVector` headers in:
   - `vexdb-duck/functions/distance_functions.cpp`
   - `vexdb-duck/index/graph_index.cpp`
   - `vexdb-duck/optimizer/vex_physical_create_index.cpp`
2. Adapted optimizer/index scan code to DuckDB 1.5.2 planner API:
   - `TableIndex` instead of raw `idx_t` where required
   - `ProjectionIndex` when constructing `ColumnBinding`
3. Fixed out-of-tree extension version metadata:
   - `/tmp/vexdb-duck-config/vexdb_duck_extension.cmake`
   - explicit `EXTENSION_VERSION v1.5.2`
4. Disabled x86 SIMD dispatcher compilation for arm64 in `vexdb-duck/CMakeLists.txt`.
5. Forced Duck/arm64 shared distance ISA dispatch back to `GENERAL` only in `distance/core/architecture_macro.h`, because the repository does not provide arm NEON/SVE dispatcher translation units.

## SIFT Dataset Preparation

Downloaded standard `SIFT1M` source files into:

- `/Users/sunji/Work/VexDB-Lite/vexdb-duck/test/benchmark/data`

Remote source used:

- `https://huggingface.co/datasets/qbo-odp/sift1m/resolve/main/sift_base.fvecs?download=true`
- `https://huggingface.co/datasets/qbo-odp/sift1m/resolve/main/sift_query.fvecs?download=true`
- `https://huggingface.co/datasets/qbo-odp/sift1m/resolve/main/sift_groundtruth.ivecs?download=true`

Generated benchmark-local files:

- `sift_train_10k.fbin`
- `sift_train_100k.fbin`
- `sift_query_200.fbin`
- `sift_gt_10k_200q.ibin`
- `sift_gt_100k_200q.ibin`

Generation rule:

- train set = first `10k` / `100k` vectors from `sift_base.fvecs`
- query set = first `200` vectors from `sift_query.fvecs`
- ground truth = exact L2 top-100 recomputed locally against the corresponding `10k` / `100k` subset
